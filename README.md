# Text to JSON Converter with Qwen

## 📌 توضیح
یک سیستم که متن آزاد فارسی را می‌گیرد و به JSON ساختاریافته تبدیل می‌کند.

## 🎯 نتیجه
- JSON معتبر: ۶/۶ = ۱۰۰٪
- ساختار: بی‌نقص
- کیفیت معنی: ۲ عالی، ۲ متوسط، ۲ ضعیف

## 🛠️ تکنولوژی
- Qwen2.5-1.5B-Instruct
- Hugging Face Transformers
- Kaggle GPU T4

## 📊 جدول ارزیابی
| ورودی | type | priority | نتیجه |
|--------|------|----------|--------|
| جلسه با تیم فروش، فوری | event ✅ | high ✅ | 🟢 عالی |
| یادم باشه شیر بخرم | note ❌ | low ✅ | 🟡 باید task باشد |
| گزارش مالی این هفته | task ✅ | medium ✅ | 🟢 عالی |
| رفتم دکتر | note ✅ | low ✅ | 🔴 title اشتباه |
| پروژه تا آخر ماه | task ✅ | high ✅ | 🟢 عالی |
| قرار با علی فردا | note ❌ | low ❌ | 🟡 باید event باشد |

## 📝 درس‌های گرفته‌شده
- Prompt Engineering سخت است.
- مدل کوچک گاهی نوع را اشتباه تشخیص می‌دهد.
- «یادم باشه» را note تشخیص داد، ولی باید task باشد.
- برای تولید پایدار، مدل بزرگ‌تر (Qwen 7B) بهتر است.
