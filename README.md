# Text to JSON Converter with Qwen

## 📌 توضیح
یک سیستم که متن آزاد فارسی را می‌گیرد و به **JSON ساختاریافته** تبدیل می‌کند. این همان کاری است که در محصولات تجاری AI انجام می‌شود تا خروجی مدل قابل استفاده در برنامه‌ها باشد.

## 🎯 هدف
- تبدیل متن آزاد به داده‌ی ساختاریافته (JSON)
- استخراج: نوع، عنوان، زمان، اولویت، برچسب‌ها
- کاربرد: مدیریت تسک، تقویم، یادداشت‌برداری خودکار

## 🛠️ تکنولوژی
- Qwen2.5-1.5B-Instruct
- Hugging Face Transformers
- PyTorch
- Kaggle (GPU T4)
